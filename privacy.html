docs-editor 隐私权政策

docs-editor 是个人使用的 Google 文档编辑工具，仅供开发者本人使用。

访问的数据

应用在用户授权后，读取和修改用户指定的 Google 文档，并通过 Google Drive API 管理这些文档文件。

数据的存储与共享

应用不会收集、上传、出售或与任何第三方共享用户数据。授权令牌只保存在用户自己的本地电脑上，不会发送到任何其他服务器。

撤销授权

用户可随时在 Google 账号的“第三方应用和服务”设置中撤销授权。

Google API 服务用户数据政策

docs-editor 对从 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的有限使用要求。
